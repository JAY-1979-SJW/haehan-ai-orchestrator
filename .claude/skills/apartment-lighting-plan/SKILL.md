# 아파트 단지별 조명 배치 3D 콘텐츠 (지역 타겟 유입)

반딧불 전파사(big.sun2024) 인스타 성장 전략의 핵심 축.
**"단지명 + 평형 타입"** 을 명시한 조명 배치 콘텐츠로, 그 단지 입주 예정자를
정확히 겨냥해 끌어온다. 콘텐츠 하나가 수백 세대에게 통한다.

## 왜 이게 먹히는가 (2026-08-19 인스타 실조사 근거)

`#조명인테리어` 인기 게시물을 실제로 열어보니, 반응 좋은 계정들이 공통으로
**단지명·평수를 제목에 박는다**:

```
"대전) 호반써밋유성 30py대 실링팬, 조명"
"서산 중흥 84㎡ A타입"
"우장산 힐스테이트 33평"
```

이유: 입주 예정자는 **자기 단지·자기 타입을 검색한다**. "거실 조명"보다
"다산 자이 84A 조명"이 검색량은 적지만 **전환율이 비교 불가**다.
지역 시공업은 전국 노출이 아니라 반경 10km 유입이 매출로 이어진다.

## 워크플로

```
1) 단지·타입 선정   남양주 다산신도시 주력 단지의 대표 평형(84A, 59B 등)
                    → 입주 시기가 가까운 단지 우선 (조명 결정 시점)
2) 평면도 확보      분양 홈페이지·부동산 사이트 공개 자료 (⚠ 저작권 주의, 아래 참조)
3) 조명 배치 설계   실별 라인조명/다운라이트/간접조명 위치·개수 산정
4) 3D 시안 제작     CAD(정확한 배치) + GPT 이미지(분위기 렌더) 조합 — 아래 역할 분담
5) 콘텐츠 발행      instagram-marketing 스킬의 정보성 캐러셀 워크플로 사용
                    제목에 반드시 「단지명 + 타입」 명시
6) 문의 응대        DM/전화 → 실제 상담·시공
```

## CAD vs GPT — 역할을 나눈다

| | 용도 | 한계 |
|---|---|---|
| **CAD** (`C:\work\03. cad-program`) | 실제 치수 반영한 **정확한 조명 배치도** | 분위기 표현은 약함 |
| **GPT 이미지 생성** | "이런 느낌이 됩니다" **분위기 렌더** | 치수·구조가 정확하지 않음 |

⚠️ GPT 결과물을 "우리 집 그대로의 3D"라고 표현하지 말 것.
고객 응대·캡션에서는 **"조명 배치 시안"** 으로 표현해야 기대 불일치가 없다.
정밀 3D가 필요하면 CAD 경로로 올린다.

## 저작권 주의

- 건설사·분양대행사 평면도를 **그대로 게시하지 않는다.**
- 참고해서 **다시 그린 배치도**나 GPT로 새로 생성한 이미지를 쓴다.
- 단지명 언급 자체는 문제없다(사실 적시). 단, 해당 단지 공식 계정을 사칭하거나
  분양 관계자인 것처럼 오해를 주는 표현은 쓰지 않는다.

## 콘텐츠 포맷 (검증된 패턴)

제목 예시:
- `다산 OO아파트 84A 조명 배치, 이렇게 하세요`
- `59㎡ 신혼집 조명 몇 개가 적당할까요`

본문 구성:
1. 훅 — "입주 앞두고 조명 때문에 고민이시죠"
2. 실별 배치 (거실/주방/침실/현관) — **개수와 위치를 구체적 숫자로**
3. 흔한 실수 — "다운라이트만 20개 달면 삭막해집니다"
4. 오퍼 — 3D 배치 시안 무료 제작
5. DM/전화 유도 + 지역 해시태그

시공 내역은 **구체적 스펙으로 적는다**(인기 계정 공통점):
> 거실 3인치 다운라이트 8개 / 커튼박스 간접조명 / 주방 라인조명 1.8m / 식탁 펜던트

## 확장

같은 단지의 여러 타입(84A/84B/59A)으로 시리즈화하면 콘텐츠가 배로 늘고,
"이 단지는 이 업체가 잘 아는구나"라는 인식이 생겨 문의가 집중된다.

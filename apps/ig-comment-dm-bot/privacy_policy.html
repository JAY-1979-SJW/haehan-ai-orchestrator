01수집하는 정보

이 프로그램은 Instagram Graph API(graph.instagram.com)를 통해 반딧불 전파사 계정이 소유한 게시물에 달린 댓글만 조회합니다. 다른 계정의 게시물이나 Instagram 외부의 정보는 전혀 수집하지 않습니다.

항목내용출처
댓글 텍스트 키워드 일치 여부를 판단하기 위해 일시적으로 확인 Instagram Graph API
댓글 작성자 사용자명 발송 로그 표시용으로 화면에만 표시, 별도 저장 안 함 Instagram Graph API
댓글 ID 중복 DM 발송을 막기 위해 로컬에 기록 Instagram Graph API
Instagram 액세스 토큰 API 인증용, 운영자 PC에 암호화 저장 운영자가 Meta 개발자센터에서 직접 발급

수집하지 않는 것: 이름, 전화번호, 주소, 위치정보, 결제정보 등 민감정보는 일절 수집하지 않습니다. 댓글 본문 내용 자체도 서버나 파일에 저장하지 않고, 키워드 매칭 직후 메모리에서만 처리한 뒤 버려집니다.

02이용 목적

  1. 댓글에 특정 키워드(예: "문의", "가격")가 포함되어 있는지 자동으로 확인합니다.
  2. 키워드가 일치하면 Instagram 공식 Private Reply 기능으로 해당 댓글 작성자에게만 비공개 답장(DM)을 1회 발송합니다.
  3. 동일한 댓글에 중복으로 DM이 발송되지 않도록 처리 이력을 관리합니다.

그 외의 목적(광고, 프로파일링, 통계 분석, 재판매 등)으로는 어떠한 정보도 이용하지 않습니다.

03저장 방식과 위치

이 프로그램은 서버를 운영하지 않는 로컬 데스크톱 프로그램입니다. 모든 데이터는 운영자(반딧불 전파사)의 PC 안에서만 처리·저장되며, 외부 서버로 전송되지 않습니다.

  • Instagram 액세스 토큰 — OS 자격증명 저장소(Windows 자격 증명 관리자)에 암호화 저장
  • 처리한 댓글 ID 목록 — 로컬 SQLite 파일(processed_comments.db)에 댓글 ID와 매칭된 키워드만 기록, 댓글 본문은 저장하지 않음

04보관 기간

댓글 ID는 중복 발송 방지라는 목적이 달성된 이후에도 재확인용으로 로컬에 남아있을 수 있으며, 운영자가 프로그램을 삭제하거나 로컬 데이터 파일을 삭제하면 즉시 전체 삭제됩니다. Instagram 액세스 토큰은 운영자가 직접 앱 연결을 해제하거나 재설정할 때까지 보관됩니다.

05제3자 제공

수집한 정보를 광고주, 데이터 브로커, 분석 업체 등 어떠한 제3자에게도 판매·공유·양도하지 않습니다. 정보는 오직 Instagram Graph API 호출(댓글 조회, DM 발송)에만 사용됩니다.

06이용자 권리와 삭제 요청

댓글을 남긴 Instagram 이용자는 아래 문의처로 연락해 본인의 댓글과 관련해 로컬에 저장된 기록(댓글 ID)의 삭제를 요청할 수 있습니다. 요청 확인 후 영업일 기준 7일 이내에 해당 기록을 삭제하고 결과를 안내해 드립니다.

삭제 요청은 다음 정보를 포함해 연락 주시면 처리됩니다.

  • 댓글을 남긴 게시물 링크 또는 대략적인 시점
  • 연락 가능한 이메일 또는 전화번호(확인용, 저장하지 않음)

07보안 조치

  • 액세스 토큰은 평문 파일이 아닌 OS 레벨 암호화 저장소에만 보관됩니다.
  • 프로그램은 인터넷상 어떤 원격 서버로도 데이터를 전송하지 않으며, Instagram 공식 API 엔드포인트(graph.instagram.com)와만 통신합니다.
  • 소스 코드는 비공개로 관리되며 운영자 본인만 접근·수정합니다.

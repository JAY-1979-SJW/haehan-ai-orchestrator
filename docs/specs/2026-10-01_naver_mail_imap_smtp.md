# 네이버 메일 수신·발송 (공식 IMAP/SMTP) — 기준서 겸 설정 절차서

- 날짜: 2026-10-01 / 사용자 요청: "네이버 이메일 수신하고 발송하는 기능을 구현하자", "공개기능을 확인해서 처리해봐"
- 결론: 네이버는 REST 메일 API 가 없고 **표준 프로토콜(IMAP/POP3/SMTP)을 공식 지원**한다. 브라우저로 웹 화면을 읽는 기존 방식(`scripts/naver/mail_read`)보다 안정적이라 프로토콜 방식으로 간다.
- 이 문서의 1~4절은 **다른 사람이 처음 설정할 때 그대로 따라 하는 절차**, 5절부터는 구현·검증·함정 기록이다.

## 1. 한눈에 보는 값 (네이버 공식 화면 "메일 프로그램 환경 설정 안내" 기준)
| 항목 | 값 |
|---|---|
| 수신 IMAP | `imap.naver.com` 포트 `993`, SSL |
| 수신 POP3 | `pop.naver.com` 포트 `995`, SSL (이 프로젝트는 IMAP 사용) |
| 발송 SMTP | `smtp.naver.com` 포트 `465`(SSL) 또는 `587`(TLS) |
| 로그인 아이디 | 네이버 아이디(이메일 주소 아님) |
| 로그인 비밀번호 | **애플리케이션 비밀번호** — 네이버 로그인 비밀번호는 거부된다 |
| 설정 화면 | https://mail.naver.com/v2/settings/smtp/imap |

## 2. 설정 절차 (사람이 하는 방법) — 순서 중요
1. **2단계 인증 켜기**: 네이버 > 내정보 > 보안설정 > 2단계 인증. (켜면 "2단계 인증 로그인이 설정되었습니다" 알림 메일이 온다.)
2. **애플리케이션 비밀번호 만들기**: 같은 보안설정의 "애플리케이션 비밀번호 관리"에서 새로 만든다. 한 번만 보여 주므로 바로 복사한다.
   - 만들 때마다 "2단계 인증을 위한 애플리케이션 비밀번호 생성" 알림 메일이 온다. 여러 번 만들어도 각각 유효하지만, 안 쓰는 것은 삭제한다.
3. **IMAP/SMTP 사용 켜기** ← 가장 많이 빠뜨리는 단계:
   네이버 메일 > 왼쪽 아래 **환경설정** > **POP3/IMAP 설정** > **IMAP/SMTP 설정** 탭 > "IMAP/SMTP 사용"을 **사용함**으로 선택 > **저장**.
   저장하면 "IMAP/SMTP가 사용함으로 설정되었습니다" 창이 뜬다. (POP3/SMTP 탭은 별개 설정이다. 이 프로젝트는 IMAP/SMTP 탭을 쓴다.)
4. **비밀번호를 `.env` 에 넣기** (저장소에 올라가지 않는 파일):
   `NAVER_MAIL_PW_<아이디 대문자>=앱비밀번호` 한 줄. 예: `NAVER_MAIL_PW_SKYJWSIN=xxxxxxxxxxxx`
   - 따옴표·공백 없이 `=` 바로 뒤에. 채팅·문서·커밋에 비밀번호를 붙여넣지 않는다.
5. **확인**: 앱의 "예약 작업" 화면에서 `네이버 메일 IMAP/SMTP 점검` 작업을 만들어 "지금 실행"하거나, 아래 6절의 명령을 실행한다.

## 3. 앱에서 자동으로 하는 방법 (이 프로젝트의 파이프라인)
앱 > **예약 작업**에서 아래 작업을 고르면 위 2-3 단계 중 사람이 꼭 해야 하는 것(2단계 인증·앱 비밀번호 생성·`.env` 입력)을 뺀 나머지를 한다.
| 작업 | 하는 일 | 승인 |
|---|---|---|
| `네이버 메일 IMAP/SMTP 점검` (`naver_mail_check`) | 웹메일의 "IMAP/SMTP 사용" 상태 + IMAP/SMTP 로그인을 **읽기 전용**으로 확인. 안 되면 원인과 해결 작업을 결과에 적어 준다 | 불필요 |
| `네이버 메일 IMAP/SMTP 켜기` (`naver_mail_enable`) | 로그인된 CDP 브라우저에서 3단계를 대신 한다("사용함" 선택 → 저장 → 다시 읽어 반영 확인). 이미 켜져 있으면 아무것도 바꾸지 않는다 | **필요**(계정 보안 설정 변경) |
- 먼저 `네이버 로그인 확인·자동 로그인` 작업으로 로그인돼 있어야 한다. 로그아웃이거나 다른 계정이면 바꾸지 않고 이유를 알린다.
- 순서: 점검 → (사용 안 함이면) 켜기 승인 → 점검 재실행.

## 4. 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| `Authentication failed. (Please check IMAP/SMTP settings in the webmail)` | **웹메일에서 IMAP/SMTP 가 "사용 안 함"** 이거나 앱 비밀번호가 틀림 (2026-10-01 실제 원인은 "사용 안 함"이었다) | 2절 3단계를 저장했는지 확인 → 앱 비밀번호 재확인 |
| 같은 오류인데 설정은 "사용함" | 일반 비밀번호를 넣었거나, 다른 계정에서 만든 앱 비밀번호, 복사 누락 | 앱 비밀번호를 새로 만들어 `.env` 교체 |
| `.env 에 NAVER_MAIL_PW_... 가 없습니다` | 4단계 미실시/이름 오타 | 아이디를 **대문자**로 맞춘다 |
| 점검은 되는데 어느 날부터 거부 | 90일 미사용 시 네이버가 "사용 안 함"으로 자동 변경 | `네이버 메일 IMAP/SMTP 켜기` 실행 |
| 로그인 실패를 반복 | 계정 잠금 위험 | **한 번 실패하면 원인을 고친 뒤에 다시** 시도. 점검 코드는 IMAP 이 거부되면 SMTP 를 시도하지 않는다 |
| 앱 종료 후 로그아웃 | 앱이 끝날 때 CDP 브라우저도 같이 종료(세션 쿠키 소멸) | `네이버 로그인 확인·자동 로그인` 작업. 캡차·2차 인증이 뜨면 사람이 처리 |

## 5. 구현 (코드)
| 파일 | 역할 |
|---|---|
| `scripts/naver/mail_imap/protocol.py` | IMAP/SMTP 로그인 점검(읽기 전용). 비밀번호는 `.env` 에서만 읽고 결과·오류에 남기지 않는다. IMAP `STATUS` 만 써서 읽음 표시를 바꾸지 않고, SMTP 는 로그인만 하고 보내지 않는다 |
| `scripts/naver/mail_imap/settings.py` | 웹메일 "IMAP/SMTP 사용" 읽기·켜기(CDP). 로그인 안 됨·화면 못 읽음·다른 계정이면 바꾸지 않는다. 저장 뒤 새로 읽어 반영을 확인 |
| `ai_orchestrator/workflows/scheduled_job_actions.py` | 위 두 기능을 앱 "예약 작업"에 `naver_mail_check`(무인)·`naver_mail_enable`(승인형)로 등록 |
| `configs/vendor_apis.json` | 벤더 공식 API 목록에 "네이버 메일 IMAP/SMTP" 추가 → `capability_check` `[0]` 에 표시 |
| `tests/test_naver_mail_imap.py` | 가짜 IMAP/SMTP·가짜 웹메일 화면으로 검증(네이버 서버·브라우저 불필요) |

### 웹메일 화면 선택자 (2026-10-01 실측 — 화면이 바뀌면 `settings.py` 상단 상수만 고친다)
- 설정 주소 `https://mail.naver.com/v2/settings/smtp/imap`, 사용함 라디오 `input#option_radio_1`(`label[for=option_radio_1]` 클릭), 저장 `button.button_settings_confirm`.
- 왼쪽 메뉴의 "환경설정" 은 `a.mailbox_link` 이고 주소로 바로 가면 메뉴를 찾을 필요가 없다(`get_by_text("환경설정")` 은 숨은 요소를 먼저 집어 실패한다).

## 6. 직접 확인하는 명령 (비밀번호는 출력되지 않는다)
```
python -c "from scripts.naver.mail_imap import protocol as p; r=p.check('skyjwsin'); print(p.describe(r))"
```
기대 출력 예: `IMAP: 폴더 14개, 받은편지함 155통(안 읽음 76) | SMTP: 인증 성공`

## 7. 이번(2026-10-01)에 실제로 한 일과 검증
- 점검 전: IMAP 서버 접속은 되는데 로그인이 `Authentication failed (Please check IMAP/SMTP settings in the webmail)` 로 두 번 거부(아이디만 / 이메일 주소 형식 모두).
- 원인: 웹메일 IMAP/SMTP 설정 화면이 **"사용 안 함"**. CDP 로 `skyjwsin` 계정에서 "사용함" 선택 → 저장 → 네이버 확인 창 "IMAP/SMTP가 사용함으로 설정되었습니다".
- 결과: IMAP 로그인 성공(폴더 14개, 받은편지함 155통·안 읽음 76 = 웹 화면과 일치), SMTP(465/SSL) 인증 성공(`235 Accepted`). 메일은 보내지 않았다.
- 공식 출처: 네이버 메일 설정 화면의 "메일 프로그램 환경 설정 안내"(POP `pop.naver.com:995`, IMAP `imap.naver.com:993`, SMTP `smtp.naver.com:465`/`587`). 보조로 여러 설정 안내 사이트와 값이 일치. (검색 도구가 naver.com 을 막아 도움말 페이지는 직접 열지 못했고, 위 설정 화면에서 직접 확인했다.)

## 8. 다음 단계 (미구현)
- IMAP **수신**: 받은편지함 목록·안 읽은 메일·본문 읽기(`BODY.PEEK`, 읽음 표시 유지) — 기존 받은편지함 수집 구조에 연결.
- SMTP **발송**: 예약 작업 `mail_send`(승인형)로 등록 — 승인 화면에 수신자·제목·본문을 그대로 표시, 시험은 본인에게 1통.
- 위 두 가지는 사용자 확인 후 진행한다. 이 문서의 1~7절은 그 전 단계(설정·점검·앱 파이프라인)까지의 기록이다.

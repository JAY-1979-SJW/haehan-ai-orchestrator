# 기준서 — 카페 수집 + 수집 내용 AI 분석 (카테고리 분류 제거)

작성일: 2026-06-05 / 대상: 네이버 카페 수집·분석
사용자 결정(최종): **"키워드로 하지말고 전체를 그냥 수집하고 수집한 내용을 분석만 해"**

## 1. 배경 / 방향 전환

- 초기안: 카페별 적응형 **키워드 카테고리 분류**(AI taxonomy 도출 + 키워드 매칭).
- **드라이런 결과**: AI가 카페에 맞는 카테고리(쇼핑/물류/구매대행 등)를 정확히 도출했으나,
  키워드 정확매칭만으로는 **76%가 "기타"**로 빠짐(제목에 카테고리 키워드가 없는 글 다수).
- 사용자 판단: 분류(카테고리) 자체를 **하지 않기로**. → **전체 수집 + 수집 내용 AI 분석만**.

## 3. 동작

```
[내 카페 목록] 기간 선택(1주~전체) → [게시글 수집]  # 게시판 구분 없이 전체글
        ↓
[수집 게시글] 수집된 글 목록(유형·제목·날짜·조회·신뢰도). 카테고리 컬럼/필터 없음.
        ↓
[AI 분석] 탭 열면 자동: 전체 수집분 중 조회수 상위 N건 → GPT 분석
        → 전체 흐름 / 🔥뜨는 흐름 / 🧩토픽 비중 / 💰수익 기회 / ✅바로 할 액션
```

- AI 분석은 카페가 바뀌면 **그 카페 내용으로 자동 적응**(GPT가 실제 제목을 읽음).
- 검증(드라이런): 셀러오션 → "중국 구매대행/물류/스마트스토어" 흐름·기회 정상 도출.

# 사이트 업무 지도 M5 — 지도 기반 실행기 (기준서)

- 날짜: 2026-10-04 / 승인: 사용자 "네"(M5 진행 — 탐색 → JSON → 다음에 JSON 으로 업무 수행을 완성). 상위: `2026-10-03_site_task_map.md` §5.
- 목적: 저장된 업무 지도의 **`read` 등급 절차를 결정론적으로 재생**하고, 결과 표를 읽어 돌려주며, 성공/불일치를 지도에 자동 기록한다.
- 선행 확인: `capability_check` replay/recorder → 기존 구현 없음. 기존 `scripts/browser/agent/universal_actions.py` 는 **처음 보는 사이트용 폴백**(접근성 트리 `ref` 기반 즉석 조작)이라 역할이 다르다. M5 는 **이미 지도에 있는 업무의 재생**이며 두 모듈을 섞지 않는다.

## 1. 하는 것 / 하지 않는 것
| 하는 것 | 하지 않는 것 |
|---|---|
| `risk == read` 업무의 `navigate`·`change`·`click` 재생 | `write`·`submit`·`login` 업무 실행(서버가 거부 — 클라이언트 표시를 믿지 않음) |
| 사용자(또는 AI)가 준 **매개변수**를 `{{이름}}` 자리에 넣음 | 매개변수·결과 **값을 지도에 저장**(구조만: 결과 표의 열 이름만 `outputs` 에 기록) |
| 새 전용 탭에서 실행 후 그 탭만 닫음(`cdp_tabs`) | 사용자 탭 이동, 로그아웃, 쿠키 삭제 |
| 지도의 호스트와 **같은 호스트**의 주소만 이동 | 다른 호스트로 이동하는 `navigate`·리다이렉트 이후 조작 |
| 성공 → `verified`, 필드·주소 불일치 → `stale`(재탐색 제안) | 결과가 없다는 이유만으로 `stale` 로 바꾸기 |

## 2. 재생 규칙 (Recorder JSON 호환 단계)
1. **사전 검사(서버 쪽)**: 업무 존재, `risk == read`, 단계 형식, 모든 `{{이름}}` 에 매개변수 존재·초과 매개변수 거부, 값은 문자열 200자 이내·제어문자 금지.
2. **navigate**: `http(s)` + 지도 호스트와 같은 호스트만. 아니면 즉시 중단(오류).
3. **change**: `selectors` 를 앞에서부터 시도 — CSS(`[name='x']`) → `aria/라벨`(접근성 이름) → 못 찾으면 **불일치(stale)**. `select` 는 옵션 선택, `radio`·`checkbox` 단계는 건너뜀(지도가 값을 담지 않음). 값은 키 입력 시뮬레이션(`fill`)으로 넣음.
4. **click**: `aria/이름`(링크·버튼 역할) → `text/이름` 순. **같은 이름이 여럿이면 마지막으로 입력한 칸의 같은 폼 안에서 그 뒤에 있는 것**을 우선하고(없으면 같은 폼 안 → 입력칸 뒤 → 전체 순), 각 단계에서는 문서 순서로 가장 가까운 것을 고른다(실사이트: KISCON 은 머리글 검색과 본문 검색의 "검색" 링크가 둘이고 폼 하나가 페이지 전체를 감싼다. 단순 "가장 가까운 것"은 선택 상자·옵션이 끼면 머리글 쪽을 눌러 시험에서 잡아 고쳤다). 클릭 뒤 `domcontentloaded` 까지 기다림.
5. **시간 상한**: 한 번 실행 25초(앱 `call_api` 호출 상한 30초 안), 단계별 8초, 이동 20초. 넘으면 오류(`stale` 로 바꾸지 않음 — 네트워크 문제와 구조 불일치를 구분).
6. **결과 읽기**: 실행 뒤 화면에서 머리글이 2열 이상이고 데이터 행이 있는 표(`<table>`) 중 가장 큰 것 하나(행 50개·칸 120자 상한). 없으면 `tables: []`.
7. **기록**: 모든 단계를 끝내고 결과 표 머리글이 있으면 `verified` + `outputs` 열 이름 갱신. 단계 중 요소를 못 찾으면 `stale`(실패 횟수 +1). 단계는 성공했지만 표가 없으면 상태 불변(결과 없음 ≠ 구조 불일치).
8. **호출 제한**: 같은 호스트는 직렬 실행 + 호출 간 최소 2초(설정값). 동시에 한 건만.

## 3. 구성
| 계층 | 파일 | 역할 |
|---|---|---|
| L1 | `domain/site_task_map.py` 에 `validate_run_request(task, params)`·`apply_outputs(site_map, task_id, headers)` 추가 | 순수: 매개변수 검증, 열 이름 반영 |
| L6 | `scripts/explorer/task_runner.py` | 재생·결과 읽기·기록(탐색 `task_mapper` 와 같은 L6 어댑터) |
| L6 | `services/site_task_map_service.py` 에 `run_task()` | 실행기는 주입(`configure`) — 브라우저 모름 |
| L8 | `routers/site_task_map_router.py` `POST /site-map/{host}/run` | 관리자 전용 |
| AI | `mcp_server` `sitemap.run` | **`read` 업무만**(서버가 강제). 승인·확정은 여전히 허용 목록에 없음 |
| 화면 | `/site-map` 업무 상세에 "실행" (매개변수 입력칸 + 결과 표) | read 업무에만 표시 |

## 4. 안전 요약
- 위험 등급 검사는 서버에서(`task.risk != read` → 400). 지도 파일을 사람이 고쳐도 `submit`→`read` 로 낮출 수 없음(M1 병합 규칙 유지).
- AI 가 `sitemap.run` 으로 실행해도 읽기 전용이고 같은 호스트·전용 탭·상한이 적용된다. 결과 값은 응답으로만 돌려주고 저장하지 않는다.
- 로그인 필요 사이트는 사용자가 이미 로그인한 브라우저 세션을 쓰며, 세션을 만들거나 지우지 않는다(인증서/OTP 는 사람).

## 5. 검증 계획
1. 순수 규칙·서비스·라우터·허용 집합 시험(가짜 실행기).
2. 실행기 시험: 가짜 페이지로 흐름·거부·기록, **실제 브라우저(격리 헤드리스 Chrome)로 로컬 HTML**(같은 이름 "검색" 둘 + 입력칸 + 결과 표) — 가까운 쪽 클릭, 표 읽기, 불일치 시 `stale`.
3. 실사이트: KISCON "업체정보 검색"을 지도 절차대로 실행(격리 브라우저)해 결과 표와 `verified` 전환 확인.
4. 게이트·`verify_change`.

# 건설 AI 자동화(적산·물량산출·내역서) 마케팅 계획서

작성일 2026-08-16 · 근거: 네이버 "건설공무" 카페 전수 수집(21,187건, 2018-08~2026-08,
게시판별 백필 포함) + YouTube Data API 실측 + 경쟁 제품 실사용 확인

---

## 1. 타겟

| 구분 | 정의 |
|---|---|
| **1차 타겟(제품)** | 건설공무·적산 실무자 — 네이버 "건설공무" 카페 24.3만명 규모 커뮤니티가 표본 |
| **2차 타겟(콘텐츠)** | 건설업 종사자로 한정. 범용 사무직·일반 자영업으로 확대하지 않음(포지셔닝 희석 방지) |

카페 실데이터 상, 회원들의 실질 관심사는 "적산/내역서" 실무 문제 + "고용·노무·구인구직" 생계
이슈 두 축이다. 제품은 전자, 콘텐츠 소재는 두 축 모두에서 끌어온다.

## 3. 경쟁 구도

| 경쟁자 | 형태 | 강점 | 약점 | 위협도 |
|---|---|---|---|---|
| **PYON Vision (PYON RC)** | 개인 개발, 특허 출원 완료, 카페 내 베타테스터 모집(댓글 247명 대기) | 실수요 검증 완료, 특허 출원 | 유튜브 구독자 10명, 영상 조회수 897/148/34 — 마케팅 역량 전무. **실사용 확인 결과 완성도 부족**(내부 확인, 2026-08-16) | 중 — 기술보다 시장검증 사례로 참고 |
| **ConPublicAI** | 1인 개발 추정, 무료 LLM 기반 법령 RAG 챗봇 | 국가계약법 조문 정확 인용 확인됨(실사용 검증) | 법령 Q&A 단일 기능, 적산/물량산출 없음 | 중 — 기능 흡수 후보 |
| **고려전산(EMS)** | 기존 적산 프로그램 강의사업 | 카페 운영진과 협찬 관계로 채널 장악 | AI 미적용, 전통 강의형 | 낮음(직접 경쟁 아님) |

**시사점**: 이 시장은 "수요는 확실히 있는데 제대로 실행하는 곳이 없는" 상태. PYON Vision 사례가
그 증거 — 카페 안에서 폭발적 반응(247명 대기)에도 마케팅·완성도가 못 따라감.

## 4. 가격 구조

| 등급 | 내용 |
|---|---|
| 무료 | 물량산출 웹앱 1일 3건, PDF/이미지만 다운로드(워터마크), 저장 불가. GPT 활용 교육 콘텐츠 전부 무료 공개 |
| 개인 구독 | 월 1.9만~2.9만원 — 무제한 사용, xlsx 다운로드, 결과 저장/이력, 내역서 자동 연동 |
| B2B | 견적 기반 — 다중 사용자, 배치 처리, 사내 단가표 연동, 전담 지원 |

카페 특성상 "무료 정보 선호"가 강함(고려전산 무료교육, 공제조합 협찬 사례) → 무료 단계를 충분히
두고, 실제 매출은 B2B(회사 단위 도입)에서 확보하는 구조.

## 5. 포지셔닝

**얼굴 비공개 + 본인 육성 + "건설 전문 AI 강사" 브랜딩 + 법적 근거 인용 + 본인 건설경력 신뢰.**
법령 조문은 사전 원문 대조 없이 자막에 넣지 않는다(창작 금지 원칙, `[확인 필요]` 표기 유지).

## 7. 배포 채널 및 형식

```
유튜브 본편(핵심, 법령근거+실시연)
  ├─ 하이라이트 3~5개 → 쇼츠 분할 발행
  ├─ 대본 재가공 → 네이버 블로그 텍스트 발행 (신규 카테고리 "AI 건설실무" 개설)
  └─ 설명란/블로그 하단 → 자체 홈페이지 CTA(무료체험) 링크
```

- 인스타그램은 쇼츠 재활용만, 별도 제작비 투입하지 않음
- **카페 유기적 홍보 금지** — ConPublicAI 사례처럼 "정보공유" 톤만 허용, 특정 카페명 노출 금지
  (저작권/배척 리스크). 유료 광고 집행은 별도 검토
- 자체 홈페이지는 발견 채널이 아니라 전환(CTA) 허브

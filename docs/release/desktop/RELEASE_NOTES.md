## 이번 버전에서 달라진 점

### 1. 글을 올리거나 메시지를 보내기 전에 "확인 문구"를 직접 입력합니다
실수로 바깥에 나가는 일을 막기 위해, 다음 작업은 **실행 직전에 확인 문구를 직접 입력해야** 진행됩니다. 입력하지 않으면 올라가거나 발송되지 않습니다.

- 네이버 블로그 글 발행
- 메일 발송(Gmail, 하이웍스 등)
- 인스타그램 게시
- 유튜브 업로드
- 스마트스토어 문의 답변
- 구글 드라이브 파일 공유
- 팩스 발송

화면에 안내된 문구를 **그대로 입력**하세요(복사해서 붙여 넣어도 됩니다). AI가 대신 입력하거나 자동으로 채워 주지 않습니다.
- **AI(Claude 등)에게 발행·발송을 시킨 경우**: AI가 확인 문구를 물으면 **사용자가 직접 입력해서 답해 주세요.** AI가 임의로 문구를 만들어 진행할 수 없습니다.
- 메일 회신 화면: "회신 발송 확인" 창에 안내 문구가 보이고, 그 문구를 입력해야 [발송] 버튼이 켜집니다.
- 블로그 발행 등 나머지 기능은 주로 AI를 통해 실행하며, 위 방식(AI가 물으면 직접 입력)으로 진행됩니다. 문구 없이 시도하면 "승인 문구가 필요합니다"라는 차단 안내가 나옵니다. 〔확정 전: 화면에 입력창이 없는 기능 목록은 배포 후 점검 3단계에서 확인〕
- 수신거부 목록에 올라 있는 상대에게는 발송되지 않습니다.

### 2. 마케팅 운영은 켜야 사용할 수 있습니다
마케팅 운영 기능(홍보 자료 만들기, 블로그 발행, 이웃 관리 등)은 **처음에는 꺼져 있습니다.** 꺼져 있으면 "설정에서 마케팅 운영을 켜세요"라는 안내가 나오고 사용할 수 없습니다. 켜고 끄는 일은 관리자만 할 수 있고, 기록이 남습니다.
- 〔확정 전: 설정 화면의 켜기 버튼은 아직 앱에 없습니다(코드에서 찾지 못했습니다). 지금은 관리자가 따로 켜 줘야 합니다. 화면 버튼이 들어가면 이 줄을 "설정 → 마케팅 운영에서 켭니다"로 바꾸세요.〕

### 3. 로그인한 계정으로 AI 콘솔을 사용합니다
AI 콘솔(첫 화면)이 이제 **로그인한 내 계정의 권한**으로 동작합니다. 작업 요청 등은 운영자·관리자·오너 권한이 필요하고, 조회 위주 계정(조회자)은 볼 수만 있습니다. 권한이 부족하면 "권한 부족" 안내가 나옵니다.
〔확정 전: 설치형 데스크톱 앱은 서버 인증을 꺼 둔 채(`AUTH_ENABLED=false`, `admin-web/electron/lib/fastapi_server.js:128`) 실행되어 서버가 모든 요청을 오너로 처리합니다. 즉 이 항목의 "계정 권한" 동작은 서버·웹 운영 환경에서만 적용되고, 데스크톱 앱 사용자에게는 눈에 띄는 변화가 없습니다. 데스크톱에서도 권한을 적용할지는 지휘창 결정이 필요하니, 결정 전에는 이 항목을 게시하지 마세요.〕

### 4. 〔확정 전〕 처음 가입한 사람은 자동으로 관리자가 됩니다
〔확정 전: 현재 코드에서는 가입한 사람이 항상 "관리자 승인 대기"가 되고, 첫 가입자를 자동으로 관리자로 올리는 기능은 아직 반영되지 않았습니다(W4 D3 구현 중). 반영되면 아래 문장을 쓰고, 안 되면 이 항목을 지우세요.〕
- 이 앱을 **처음 설치한 PC에서 가장 먼저 가입한 사람**은 승인을 기다리지 않고 바로 관리자가 됩니다. 그다음부터 가입하는 사람은 관리자의 승인이 필요합니다.

### 5. Claude와 연결할 수 있습니다
이 PC에 Claude Desktop 또는 Claude Code가 설치되어 있으면, Claude에서 Haehan AI 도구를 바로 쓸 수 있도록 연결해 줍니다.
- 앱을 처음 실행하면 **"Claude 연결" 동의 창**이 한 번 나옵니다. [연결]을 누르면 자동으로 설정되고, [나중에]를 누르면 다시 묻지 않습니다.
- 언제든 **작업표시줄 오른쪽 아래 트레이 아이콘 우클릭 → "Claude 연결" / "Claude 연결 해제"** 로 켜고 끌 수 있습니다.
- 기존 Claude 설정은 바꾸지 않고 Haehan AI 항목만 추가하며, 바꾸기 전에 백업 파일을 남깁니다. 연결 후 Claude를 한 번 껐다 켜세요.
- Haehan AI 앱이 꺼져 있으면 Claude가 "Haehan AI 앱을 실행한 뒤 다시 시도하세요"라고 알려 줍니다.

### 6. 데이터 보존 위치 〔확정 전〕
〔확정 전: 데이터를 사용자 PC의 고정 폴더로 옮기고 새 버전 실행 때 자동으로 이전하는 기능(D1)은 코드에 아직 없습니다. 반영되면 아래 문장을 쓰고, 안 되면 이 항목을 지우고 아래 "알려진 제한"을 그대로 두세요.〕
- 계정·기록 등 데이터는 이제 PC의 고정 폴더에 저장되고, 이전 버전 데이터는 **새 버전을 처음 실행할 때 자동으로 옮겨집니다.** 새 버전을 받아 실행하기만 하면 됩니다.

### 7. 버전을 확인할 수 있습니다 〔확정 전〕
- 다운로드한 파일 이름 `HaehanAI-<날짜>-<번호>-portable.exe` 가 곧 버전입니다. 문의할 때 이 이름을 알려 주세요.
- 〔확정 전: 앱 화면 안에서 버전을 보여 주는 기능은 아직 없습니다(서버에 빌드 정보를 넘기는 작업 D4 구현 중). 반영되면 "앱 안의 어디에서 보이는지"를 여기에 적으세요.〕

## 이번 버전에서 달라진 점

### 1. 글을 올리거나 메시지를 보내기 전에 "확인 문구"를 직접 입력합니다
실수로 바깥에 나가는 일을 막기 위해, 다음 작업은 **실행 직전에 확인 문구를 직접 입력해야** 진행됩니다. 입력하지 않으면 올라가거나 발송되지 않습니다.

- 네이버 블로그 글 발행
- 메일 발송(Gmail, 하이웍스 등)
- 인스타그램 게시
- 유튜브 업로드
- 스마트스토어 문의 답변
- 구글 드라이브 파일 공유
- 팩스 발송

화면에 안내된 문구를 **그대로 입력**하세요(복사해서 붙여 넣어도 됩니다). AI가 대신 입력하거나 자동으로 채워 주지 않습니다.
- **AI(Claude 등)에게 발행·발송을 시킨 경우**: AI가 확인 문구를 물으면 **사용자가 직접 입력해서 답해 주세요.** AI가 임의로 문구를 만들어 진행할 수 없습니다.
- 메일 회신 화면: "회신 발송 확인" 창에 안내 문구가 보이고, 그 문구를 입력해야 [발송] 버튼이 켜집니다.
- 블로그 발행 등 나머지 기능은 주로 AI를 통해 실행하며, 위 방식(AI가 물으면 직접 입력)으로 진행됩니다. 문구 없이 시도하면 "승인 문구가 필요합니다"라는 차단 안내가 나옵니다. 〔확정 전: 화면에 입력창이 없는 기능 목록은 배포 후 점검 3단계에서 확인〕
- 수신거부 목록에 올라 있는 상대에게는 발송되지 않습니다.

### 2. 마케팅 운영은 켜야 사용할 수 있습니다
마케팅 운영 기능(홍보 자료 만들기, 블로그 발행, 이웃 관리 등)은 **처음에는 꺼져 있습니다.** 꺼져 있으면 "설정에서 마케팅 운영을 켜세요"라는 안내가 나오고 사용할 수 없습니다.
- 켜고 끄는 곳: 왼쪽 메뉴 **설정** → **마케팅 운영** 스위치(안내 문구의 "설정으로 이동"을 눌러도 이 스위치로 바로 옵니다).
- 이 스위치는 **관리자·오너 계정에만** 보입니다. 이 앱을 처음 실행해 등록한 사람은 오너이므로 본인 PC에서는 바로 켤 수 있습니다. 켜고 끈 기록이 남습니다.
- 켜 두어도 블로그 발행은 실행 직전에 확인 문구를 직접 입력해야 합니다(위 1번).

### 3. 로그인한 계정으로 AI 콘솔을 사용합니다
AI 콘솔(첫 화면)이 이제 **로그인한 내 계정의 권한**으로 동작합니다. 작업 요청 등은 운영자·관리자·오너 권한이 필요하고, 조회 위주 계정(조회자)은 볼 수만 있습니다. 권한이 부족하면 "권한 부족" 안내가 나옵니다.
〔확정 전: 설치형 데스크톱 앱은 서버 인증을 꺼 둔 채(`AUTH_ENABLED=false`) 실행되어 서버가 모든 요청을 오너로 처리합니다. 즉 이 항목의 "계정 권한" 동작은 서버·웹 운영 환경에서만 적용되고, 데스크톱 앱 사용자에게는 눈에 띄는 변화가 없습니다(데스크톱 앱은 한 PC에서 한 사람(오너)이 쓰는 방식입니다). 데스크톱 배포 문서에서는 이 항목을 빼는 것을 권장하며, 최종 결정은 지휘창이 합니다. 결정 전에는 이 항목을 게시하지 마세요.〕

### 4. 처음 실행할 때 이름과 이메일만 한 번 입력합니다 (비밀번호 없음)
이 앱을 처음 실행하면 **"사용자 정보"** 화면이 한 번 나옵니다. **이름과 이메일**만 입력하고 [시작하기]를 누르면 끝입니다.
- **비밀번호는 없습니다.** 가입 승인을 기다릴 필요도 없습니다. 입력한 사람이 이 PC의 **오너(관리자 권한)** 로 등록됩니다.
- 그다음부터는 앱을 켤 때마다 **자동으로 로그인**됩니다. 로그인 화면이 나오지 않으며, 로그인이 풀려 다시 입력할 필요도 없습니다.
- 이 방식은 **한 PC에서 한 사람이 쓰는 것**을 전제로 합니다. 이름·이메일은 이 PC 안에만 저장됩니다.
- 왼쪽 메뉴 **설정**에서 등록한 이름과 이메일을 확인할 수 있습니다.

### 5. Claude와 연결할 수 있습니다
이 PC에 Claude Desktop 또는 Claude Code가 설치되어 있으면, Claude에서 Haehan AI 도구를 바로 쓸 수 있도록 연결해 줍니다.
- 앱을 처음 실행하면 **"Claude 연결" 동의 창**이 한 번 나옵니다. [연결]을 누르면 자동으로 설정되고, [나중에]를 누르면 다시 묻지 않습니다.
- 언제든 **작업표시줄 오른쪽 아래 트레이 아이콘 우클릭 → "Claude 연결" / "Claude 연결 해제"** 로 켜고 끌 수 있습니다.
- 기존 Claude 설정은 바꾸지 않고 Haehan AI 항목만 추가하며, 바꾸기 전에 백업 파일을 남깁니다. 연결 후 Claude를 한 번 껐다 켜세요.
- Haehan AI 앱이 꺼져 있으면 Claude가 "Haehan AI 앱을 실행한 뒤 다시 시도하세요"라고 알려 줍니다.

### 6. 데이터가 내 PC의 고정 폴더에 저장되고, 새 버전을 받아도 유지됩니다
계정 정보, 승인·감사 기록, 작업 데이터는 이제 **내 계정의 앱 데이터 폴더(`%APPDATA%\Haehan AI`)** 에 저장됩니다. 다운로드한 앱 파일이 있는 폴더나 임시 폴더가 아닙니다.
- **새 버전을 받아 실행하기만 하면 데이터가 그대로 이어집니다.** 앱 파일(`HaehanAI-<버전>-portable.exe`)을 바꿔도 데이터는 별도 폴더에 있어 사라지지 않습니다.
- 이전 버전이 앱 안쪽 위치에 저장해 둔 데이터가 남아 있으면, **새 버전을 처음 실행할 때 새 폴더로 자동 복사**됩니다. 원본은 지우지 않고 그대로 두며, 새 폴더에 이미 있는 파일은 덮어쓰지 않습니다. 한 번 끝나면 다시 하지 않습니다.
- 일부 파일을 옮기지 못해도(예: 다른 프로그램이 파일을 쓰고 있을 때) **앱은 정상적으로 시작**되고, 다음 실행에서 남은 것만 다시 시도합니다.

### 7. 버전을 확인할 수 있습니다
- 앱 안에서: 왼쪽 메뉴 **설정** 아래쪽의 **"앱 정보"** 카드에 **빌드(커밋)** 와 **빌드 시각**이 표시됩니다. 문의할 때 이 값을 알려 주세요.
- 다운로드한 파일 이름 `HaehanAI-<날짜>-<번호>-portable.exe` 도 같은 버전을 뜻합니다.
- 개발 중인 실행처럼 빌드 정보가 없으면 "알 수 없음"으로 표시됩니다.

### 8. 안정성 개선
- **앱이 갑자기 종료된 뒤 다시 실행해도 안전합니다.** 이전에 남은 앱 내부 서버를 앱이 알아서 정리하고 새로 시작합니다(내가 띄운 것만 정리하며, 다른 프로그램은 건드리지 않습니다).
- **설정 파일이 손상되어도 내용을 잃지 않습니다.** 앱 설정 파일(`config.json`)이 깨졌거나 읽을 수 없으면 "설정 파일 경고" 창이 뜨고, 깨진 파일은 `config.json.corrupt-<시각>` 이름으로 보존됩니다. 라이선스 키·로그인 정보·소유자 설정 같은 핵심 값은 가능한 한 자동으로 되살립니다. 파일이 잠겨 읽을 수 없는 경우에는 기존 설정을 덮어쓰지 않습니다.
- 내부 구조 정리와 오류 수정으로 전반적인 안정성이 좋아졌습니다.

## 알려진 제한
- 이 앱은 **Google Chrome이 설치된 PC**에서 자동화 기능이 동작합니다. 없으면 시작할 때 설치 안내가 나옵니다.
- 이 파일은 전자서명이 없어 처음 실행할 때 Windows가 "알 수 없는 게시자" 경고를 띄웁니다(설치 안내 참고).
- 한 PC는 **한 사람(오너)** 이 쓰는 방식입니다. 한 PC에서 여러 사람이 각자 계정으로 쓰는 용도는 지원하지 않습니다.
- 앱이 스스로 새 버전을 알려 주거나 내려받지는 않습니다. NAS에 올라온 새 버전을 직접 받아 실행하세요.

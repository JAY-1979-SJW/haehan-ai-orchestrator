# Haehan AI 설치 및 사용 안내

> **게시 전 확인(담당자용 — 게시할 때 지웁니다)**: 〔확정 전〕 표시는 아직 결정되지 않은 내용입니다. 결정되면 표시를 지우거나 줄을 삭제하세요. 근거: `stage/desktop-runtime-fixes`(847251f8)와 `stage/integrate-2` 코드, `docs/ops/desktop_release_ci.md`. 현재 남은 〔확정 전〕은 문의처 한 곳입니다.

Windows PC에 Haehan AI를 설치하고 쓰는 방법입니다. 설치 프로그램이 따로 없고, 받은 파일을 그대로 실행하는 방식(포터블)입니다.

## 시작하기 전에
- Windows 10/11 PC
- **Google Chrome이 설치**되어 있어야 합니다(웹사이트 자동화에 사용). 없으면 앱을 시작할 때 설치 안내가 나옵니다. Chrome을 설치한 뒤 앱을 다시 시작하세요.
- 회사에서 받은 **라이선스 키**

## 1. NAS에서 내려받기
1. NAS(Nextcloud)에서 `회사공용` → `배포` → `Haehan AI` 폴더를 엽니다.
2. 가장 새로운 버전 폴더를 엽니다(폴더 이름이 버전입니다).
3. 폴더 안의 릴리스 노트(`RELEASE_NOTES.md` 또는 `변경사항` 파일)를 읽고, `HaehanAI-<버전>-portable.exe` 파일을 내 PC의 원하는 폴더(예: 문서 안의 `HaehanAI` 폴더)에 복사합니다.
4. (선택) 파일이 온전한지 확인하려면: 시작 메뉴에서 **PowerShell**을 열고 아래를 입력한 뒤, 나온 값이 같은 폴더의 `checksums.txt` 값과 같은지 봅니다.
   `CertUtil -hashfile "받은 파일 경로\HaehanAI-<버전>-portable.exe" SHA256`

## 2. 실행하기 (Windows 경고가 나올 때)
> 예전 버전의 Haehan AI(예: `Haehan AI` 폴더)를 쓰던 PC라면, **예전 앱을 먼저 종료**하고 실행하세요. 처음 실행할 때 예전 계정·기록을 자동으로 가져옵니다(아래 3번).

1. `HaehanAI-<버전>-portable.exe`를 더블클릭합니다.
2. 처음 실행하면 파란 화면의 **"Windows의 PC 보호"(SmartScreen)** 경고가 나올 수 있습니다. 이 파일에 전자서명이 없어서 나오는 것이며, 회사에서 배포한 파일이면 정상입니다.
   - **"추가 정보"** 를 누릅니다.
   - 나타나는 **"실행"** 버튼을 누릅니다.
3. 백신 프로그램이 확인 창을 띄우면 허용해 주세요.
4. 앱이 시작되기까지 잠시 기다립니다(처음에는 더 걸립니다).

## 3. 예전 앱이 있는 PC라면: 예전 앱 데이터 가져오기 (자동 — 실패하면 수동)
예전 버전의 Haehan AI(예: `C:\Users\<사용자>\Haehan AI`)를 쓰던 PC에서는 새 앱을 **처음 실행할 때 예전 계정·기록을 자동으로 가져옵니다.** 예전 앱을 쓴 적이 없는 PC는 이 단계를 건너뛰세요.

### 자동으로 가져오기
1. **예전 앱을 먼저 종료**합니다(트레이 아이콘 우클릭 → 종료). 예전 앱이 켜져 있으면 가져오기를 건너뜁니다.
2. 새 앱을 처음 실행합니다(아래 4번). 예전 계정이 있으면 **"사용자 정보" 화면 없이** 바로 열리고 예전 소유자 계정으로 자동 로그인됩니다.
3. 복사만 하며 새 폴더에 이미 있는 파일은 덮어쓰지 않고, **예전 폴더는 그대로** 남습니다. 한 번 끝나면 다시 하지 않습니다.
4. 일부만 복사되면 완료로 처리하지 않고 다음 실행에서 남은 것을 다시 시도합니다(앱은 정상 시작).
5. 확인: 로그 파일 `%APPDATA%\Haehan AI\logs\fastapi.log` 에서 `[legacy-import]` 가 붙은 줄(복사한 파일 수 또는 건너뛴 이유)을 볼 수 있습니다.

### 자동으로 안 될 때(수동)
새 앱에서 "사용자 정보"(이름·이메일) 화면이 나왔다면 가져오기가 되지 않은 것입니다. **아직 이름·이메일을 입력하지 않았다면** 앱을 종료하고(예전 앱도 종료) 아래 두 줄을 실행한 뒤 새 앱을 다시 실행하세요. 예전 앱이 다른 폴더에 있으면 첫 줄의 경로만 바꿉니다.
```powershell
$old = "$env:USERPROFILE\Haehan AI\resources\server\haehan-server\_internal"
robocopy "$old\ai_orchestrator\storage" "$env:APPDATA\Haehan AI\storage" /E /XC /XN /XO /XD __pycache__ /XF .gitkeep
```
복사만 하며 기존 파일은 덮어쓰지 않고 예전 폴더는 그대로 남습니다. 화면에 복사된 파일 목록(예: `users.db`)이 나오면 정상입니다.
- **이미 새 이름·이메일을 등록한 뒤에는 수동으로도 가져오지 마세요**(새 계정과 예전 데이터가 섞일 수 있습니다). 문의해 주세요 — 예전 폴더는 건드리지 않았으므로 예전 앱으로 언제든 돌아갈 수 있습니다.

## 4. 처음 시작 설정
1. **라이선스 키 입력** 창이 나오면 회사에서 받은 라이선스 키를 입력합니다.
   틀리면 "유효하지 않은 라이선스 키입니다."라고 나옵니다. 키를 다시 확인하세요.
2. **"사용자 정보" 화면**이 나오면 **이름**과 **이메일**을 입력하고 **[시작하기]** 를 누릅니다.
   - **비밀번호는 없습니다.** 처음 한 번만 입력하며, 승인을 기다릴 필요도 없습니다.
   - 입력한 사람이 이 PC의 **오너(관리자 권한)** 로 등록됩니다. 한 PC는 한 사람이 쓰는 방식입니다.
   - 이름이 비어 있거나 이메일 형식이 올바르지 않으면 안내가 나옵니다. 고쳐서 다시 누르세요.
   - 이후에는 앱을 켤 때마다 **자동으로 로그인**됩니다(로그인 화면·비밀번호 입력 없음).
3. 등록이 끝나면 첫 화면인 **AI 콘솔**이 보입니다. 등록한 이름과 이메일은 왼쪽 메뉴 **설정**에서 볼 수 있고, 같은 화면 아래쪽 **"앱 정보"** 에서 이 앱의 버전(빌드)을 확인할 수 있습니다.

## 5. Claude 연결하기 (선택)
이 PC에 **Claude Desktop** 또는 **Claude Code**가 설치되어 있으면 Claude에서 Haehan AI 도구를 쓸 수 있습니다.
1. 앱을 처음 실행한 뒤 잠시 후 **"Claude 연결"** 창이 나오면 **[연결]** 을 누릅니다. (다시 묻지 않게 하려면 [나중에])
2. 연결 결과 창에 Claude Desktop / Claude Code 각각 "완료"인지 나옵니다. 설치되지 않은 쪽은 "설치 안 됨" 또는 "건너뜀"으로 나오는 것이 정상입니다.
3. **Claude를 한 번 완전히 종료했다가 다시 실행**합니다. (Claude Desktop은 창을 닫는 것만으로는 부족할 수 있어, 트레이 아이콘까지 종료하세요.)
4. Claude에서 Haehan AI 도구가 보이면 성공입니다. **Haehan AI 앱이 켜져 있어야** 도구가 동작합니다. 꺼져 있으면 Claude가 "Haehan AI 앱을 실행한 뒤 다시 시도하세요"라고 알려 줍니다.
5. 나중에 연결하거나 끊으려면: 작업표시줄 오른쪽 아래 **트레이의 Haehan AI 아이콘을 우클릭 → "Claude 연결" 또는 "Claude 연결 해제"**.
   - 기존 Claude 설정은 그대로 두고 Haehan AI 항목만 추가·제거합니다. 바꾸기 전에 백업 파일(`claude_desktop_config.json.bak-날짜시간`)이 같은 폴더에 남습니다.

## 6. 새 버전으로 업데이트하기
앱이 자동으로 업데이트하지 않습니다. 새 버전이 나오면 공지를 받고 직접 바꿉니다.
1. NAS에서 새 버전 폴더의 `HaehanAI-<새 버전>-portable.exe`를 내려받습니다(1번과 같음).
2. 실행 중인 Haehan AI가 있으면 **트레이 아이콘 우클릭 → 종료**합니다.
3. 새 파일을 실행합니다. 이전 파일은 지워도 되고 한동안 두어도 됩니다.
4. 라이선스 키·Claude 연결 설정·API 키, 그리고 계정 정보·승인/감사 기록·작업 데이터는 모두 `%APPDATA%\Haehan AI` 폴더(안의 `data`, `storage` 폴더 등)에 저장되어 있어 **새 파일로 바꿔도 유지됩니다.** 앱 파일이 있는 폴더나 임시 폴더에는 데이터가 저장되지 않습니다.
5. 이 업데이트는 **새 버전 → 더 새로운 버전**으로 바꾸는 경우입니다. 데이터는 앱 파일과 별도 폴더에 있으므로 새 파일을 실행하기만 하면 **그대로 이어집니다.** (예전 설치 폴더 `Haehan AI`에서 처음 옮겨 오는 경우는 위 3번 "예전 앱 데이터 가져오기"를 참고하세요 — 자동으로 가져오며, 실패하면 수동 방법을 씁니다.)
6. Claude를 연결해 두었다면 새 버전 실행 때 연결 경로가 자동으로 갱신됩니다(Claude를 한 번 재시작하세요).

## 7. 문제가 생겼을 때
먼저 확인하세요.
- 앱이 안 열리거나 "서버 시작 실패" / "UI 서버 시작 실패" 창이 나옵니다 → 앱을 완전히 종료(트레이 우클릭 → 종료)하고 다시 실행하세요. 계속되면 아래 로그 파일을 보내 주세요.
- 자동화(웹사이트 조작)가 안 됩니다 → Google Chrome이 설치되어 있는지 확인하세요.
- "사용자 정보" 화면이 계속 나오거나 "시작할 수 없습니다" 안내가 나옵니다 → 앱 내부 서버가 아직 뜨는 중일 수 있습니다. 잠시 기다린 뒤에도 같으면 앱을 완전히 종료(트레이 우클릭 → 종료)하고 다시 실행하세요.
- 앱이 갑자기 꺼졌습니다 → 그냥 다시 실행하세요. 이전에 남은 내부 서버는 앱이 알아서 정리하고 새로 시작합니다.
- "설정 파일 경고" 창이 떴습니다 → 설정 파일(`%APPDATA%\Haehan AI\config.json`)이 손상되었거나 읽을 수 없었다는 뜻입니다. 깨진 파일은 `config.json.corrupt-<시각>` 이름으로 같은 폴더에 보존되고, 라이선스 키·로그인 정보 같은 핵심 값은 자동으로 되살립니다. 다시 지정해야 할 설정이 있으면 설정 화면에서 다시 하세요. 같은 경고가 반복되면 `.corrupt-` 파일과 로그를 함께 보내 주세요.
- Claude에서 도구가 안 보입니다 → 트레이에서 "Claude 연결"을 다시 실행하고 Claude를 재시작하세요. 앱이 켜져 있는지도 확인하세요.

로그 파일(문의할 때 첨부):
- `%APPDATA%\Haehan AI\logs\fastapi.log` (프로그램 서버)
- `%APPDATA%\Haehan AI\logs\nextjs.log` (화면)
- 폴더 여는 방법: 키보드 **Windows 키 + R** → `%APPDATA%\Haehan AI\logs` 입력 → 확인.

앱 안에 별도의 "진단" 메뉴나 로그 내보내기 버튼은 없습니다. 버전은 **설정 → 앱 정보**에서, 로그는 위 폴더에서 확인합니다.

문의할 때 알려 주실 것: ① 버전(파일 이름의 `HaehanAI-<버전>-portable.exe`, 또는 **설정 → 앱 정보**의 빌드 값) ② 어떤 화면에서 무엇을 눌렀을 때 문제가 났는지 ③ 위 로그 파일.

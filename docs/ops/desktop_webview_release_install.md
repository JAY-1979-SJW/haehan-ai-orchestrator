# HaehanAI Desktop 설치 및 실행 안내

## 배포 파일

| 파일 | 설명 |
|------|------|
| `HaehanAI-Desktop-YYYYMMDD.zip` | 배포 zip |
| `checksums.json` | SHA256 체크섬 |

---

## 설치 방법

### 1. 압축 해제

1. `HaehanAI-Desktop-YYYYMMDD.zip` 파일을 원하는 폴더에 복사합니다.
2. 마우스 우클릭 → **압축 풀기** → 현재 폴더 또는 원하는 위치 선택
3. 압축 해제 후 폴더 구조:
   ```
   HaehanAI-Desktop/
   ├── HaehanAI-Desktop.exe   ← 실행 파일
   └── _internal/             ← 런타임 파일 (삭제 금지)
   ```

### 2. 실행

`HaehanAI-Desktop.exe` 를 더블클릭합니다.

- 첫 실행 시 Windows SmartScreen 경고가 표시될 수 있습니다.
  → **추가 정보** → **실행** 클릭

- 앱이 시작되면:
  1. 로컬 서버(포트 8765)가 자동 기동됩니다
  2. pywebview 네이티브 창이 열립니다
  3. Haehan AI 화면이 표시됩니다

### 3. 바탕화면 바로가기 만들기

1. `HaehanAI-Desktop.exe` 파일에서 마우스 우클릭
2. **보내기** → **바탕 화면에 바로 가기 만들기**

## 앱 기능 안내

| 패널 | 설명 |
|------|------|
| 대화 | AI에게 지시하거나 질문 |
| 작업 큐 | 서버에서 수신된 태스크 목록 |
| 승인 대기 | AI가 실행 전 승인 요청한 작업 목록 — 승인/거부 가능 |

| EUM 단말기 | 건설근로자공제회 단말기 임대 현황 |
| 블로그 작성 | 네이버 블로그 글 작성 + 발행 승인 |
| 카페 글쓰기 | 네이버 카페 글 작성 + 발행 승인 |
| 브라우저 상태 | AI 브라우저 백그라운드 상태 확인 |

## 문제 해결

### 포트 8765 충돌
다른 프로그램이 8765 포트를 사용 중인 경우:
1. 작업 관리자 → 8765 포트 사용 프로세스 종료
2. 앱 재실행

### 창이 열리지 않음
- 방화벽/백신이 차단한 경우: `HaehanAI-Desktop.exe` 예외 추가
- `_internal` 폴더가 삭제된 경우: zip에서 다시 압축 해제

### 서버 연결 안 됨 (연결 끊김 표시)
- 하단 사이드바의 **연결 끊김** 클릭 → 재연결 시도
- 인터넷 연결 확인
- 설정 패널에서 에이전트 등록 여부 확인

### admin 화면(관리 웹)이 안 열림
- 사용자 역할이 `Admin` 이상이어야 합니다 (설정 패널에서 변경)
- 서버(`haehan-ai.kr`) 연결이 필요합니다

### SmartScreen 경고
- **추가 정보** 클릭 → **실행** 클릭
- code signing 없이 배포된 파일이므로 경고가 표시되나 안전합니다

## 에이전트 등록 (최초 1회)

1. 사이드바 하단 사용자 아이콘 → **설정**
2. **에이전트 등록** 섹션에서 관리자로부터 받은 등록 코드 입력
3. **등록** 버튼 클릭
4. 연결 상태에 `서버 WS 연결됨` 표시 확인

## 체크섬 확인 (선택)

PowerShell에서:
```powershell
Get-FileHash "HaehanAI-Desktop.exe" -Algorithm SHA256
```

`checksums.json`의 `exe_sha256` 값과 비교합니다.

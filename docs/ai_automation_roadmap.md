# AI 자동화 로드맵 — 전 기능 정리

목표: **모든 탭이 AI 연동 자동** — 사용자는 자연어 지시 또는 원클릭, AI가 작성·실행, 사용자는 검토·최종승인만.
작성: 2026-06-04 (현재 상태 = 상당수 수동)

---

## A. 이미 AI 자동 (유지)

| 기능 | 방식 |
|---|---|
| 스마트스토어 AI 채팅 | 자연어 → 도구 실행(GPT/Claude) |
| 스마트스토어 상품 — 상세설명 빌더 | GPT 생성 + 템플릿 기반 수정 + 사진 분석 |
| 스마트스토어 AI 명령 바 | 자연어 → 등록/조회/수정 |
| 구글 허브 | 자연어 명령 |
| 가비아 | 자연어 업무 지시 |
| 공공데이터포털 | 자연어 업무 지시 |
| EUM 영업메일 | AI가 신규현장 타겟 선별 + 초안 생성 |
| 그랜트레이더 | AI 지원사업 탐색 + 초안 |
| 입찰 BID | 공고 + AI 분석(부분) |

## B. 수동 → AI 작성 필요 (생성형 — 핵심 작업 대상) ⚠️

| 기능 | 현재(수동) | AI 자동화 목표 |
|---|---|---|
| **네이버 블로그 쓰기** | 제목·태그·본문 전부 직접 입력 | 주제·키워드만 → AI가 제목·본문·태그·SEO 생성 |
| **유튜브 업로드** | 제목·설명·태그 직접 입력 | 영상 → AI가 제목·설명·태그(+자막) 생성 |
| **Gmail** | 전용 화면 없음(AI채팅으로만) | 화면 추가 + AI 작성·자동분류·요약 |
| **하나팩스** | 팩스 제목·본문 직접 입력 | 용건만 → AI가 공문/팩스 본문 작성 |
| **메일함(작성)** | 메일 본문 직접 입력 | 용건 → AI 작성 |
| **네이버 카페 글쓰기** | 수집만 있음, 작성 AI 없음 | 주제 → AI 글 작성 |

## C. 조회·수집형 (AI 요약·인사이트 추가 여지)

| 기능 | 현재 | AI 추가 |
|---|---|---|
| 스마트스토어 주문/정산/리뷰/통계/마케팅 | 수집·표시(버튼) | AI 요약·이상감지·대응제안 |
| 네이버 카페 수집 / 뉴스 / 키워드 | 수집·분석 | AI 인사이트·요약 |

## 통일 패턴 (모든 생성형 기능 공통)

```
[자연어 지시 / 주제 입력]  →  AI 생성(초안)  →  미리보기·검토  →  최종 저장/발행(사용자 승인)
```
- 상세설명 빌더의 **GPT 생성 엔진을 블로그·메일·팩스·카페에 재사용**
- 외부 발행(블로그/카페/메일/팩스)은 **최종 발행만 사용자 승인** (보안 정책)

## 실행 순서 (순서대로)

1. **스마트스토어 상품관리 마무리** — JSON→폼(완료, 빌드·배포 남음) + 탭 6→3 + ❓사용법
2. **네이버 블로그 AI 글쓰기** — 상세설명 엔진 재사용 (가장 명확한 수동→AI)
3. **유튜브 메타 AI 생성** — 제목·설명·태그·자막
4. **Gmail 화면 + AI 작성/분류**
5. **하나팩스·메일함·카페 AI 작성**
6. **조회형 AI 요약·인사이트** (주문/정산/리뷰/통계)

각 단계는 기능별 기준서 → 구현 → 빌드·배포 → 검증.

# 앱 실검증 체크리스트 (2026-10-04)

대상: `feat/gongmu-g2` @ 3b07f8f3 (origin/master 병합 후). 환경: Windows 11, Python 3.14, Next.js 14 dev, Electron(개발 모드).
방법: API(8401) + 웹(3000) + Electron(제어 포트 9333)을 기동하고, 9333 으로 앱 화면을 열어 관찰하고 AI 창에 직접 업무를 입력했다.

# 표준 UI 디자인 시스템

## 브랜드 원칙

- **Neutral 70~80%**: 배경, 카드, 텍스트 — 차분하고 신뢰감
- **Navy 10~20%**: 사이드바, 헤더 강조 — 전문성
- **Orange 5% 이하**: 액션 버튼, CTA, 아이콘 강조 — 에너지

## 필수 요소

| 요소 | 규격 |
|------|------|
| Top Accent Line | 4px, `#F97316`, 페이지 최상단 fixed |
| Sidebar | 224px, `#1E2D4A` (navyBase) |
| Card radius | 8px (--r-md) |
| Font | Pretendard (한글), -apple-system fallback |
| Base font | 14px |

## 색상 사용 기준

- 주황(#F97316): primary 버튼, 링크 강조, active nav item
- 네이비(#1E2D4A): 사이드바 배경, navy 버튼
- 배경(#F5F7FA): 페이지 배경
- 카드(#FFFFFF): 카드 배경
- 텍스트 1차(#0F172A): 제목, 강조
- 텍스트 2차(#374151): 본문
- 텍스트 muted(#6B7280): 라벨, 보조
